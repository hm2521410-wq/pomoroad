# スマホ連携の設定（Android）

Pomoroad の「見守り」をスマホにも広げる手順です。使うのは次の 2 つ（どちらも無料）。

- **MacroDroid**：スマホの自動化アプリ（Polaris の家計取り込みで使っているもの）
- **ntfy**：パソコンとスマホで知らせを中継する無料のサービス。送るのは「集中開始・集中終了」と「開いたアプリの名前」だけです

> トピック名と URL は、アプリの「設定 → 見守り → スマホ（Android）」に、あなた用のものが入った状態で表示されます（コピーボタンつき）。
> 下の `<トピック名>` はそれに置き換えてください。トピック名を知っている人は知らせを読み書きできるので、他の人に教えないでください。

## はじめに（パソコン）

1. 「設定 → 見守り → スマホ（Android）」で「スマホと連携する」をオン
2. 「つながっています」と出ればパソコン側は準備完了

## かんたん：気が散るアプリを開いたら、パソコンに知らせる

1. MacroDroid でマクロを追加し、名前を「Pomoroad 気が散るアプリ」にする
2. **トリガー**：「アプリケーション」→「アプリの起動/終了」→「起動時」→ 気が散るアプリ（YouTube・Instagram・X・TikTok・ゲームなど）を選ぶ
3. **アクション**：「Web 連携」→「HTTP リクエスト」
   - 方式：**GET**
   - URL：`https://ntfy.sh/<トピック名>-pc/publish?message=`
   - URL の最後（`message=` のあと）に、入力欄右の「…」→ マジックテキストから「アプリ名」に当たるもの（なければ「トリガー」）を入れる。入れなくても動きます（パソコンには「スマホのアプリ」と出ます）
   - **本文（ボディ）に入れた変数は置き換わらないことがある**ので、URL に入れてください（Polaris の家計取り込みで分かったこと）
4. パソコンで集中しているときにそのアプリを開くと、Pomoroad が声をかけて記録します。集中中でないときは何もしません

## しっかり：集中中はスマホもおやすみモードにする

5. スマホに **ntfy** アプリを入れ、「＋」でトピック `<トピック名>` を登録する（サーバーは ntfy.sh のまま）
6. マクロ「Pomoroad 集中開始」
   - トリガー：「通知」→「通知を受信」、アプリは ntfy、文字に「集中開始」を含む
   - アクション：「音量」→「**優先モード/通知のミュート**」→「優先通知のみ許可」（電話も止めたいなら「全通知をブロック」）、続けて変数 `pomoroad_focus` をオン（true）
   - MacroDroid に「おやすみモード」という名前のアクションはありません。「優先モード/通知のミュート」（英語表示では Priority Mode / Do Not Disturb）がそれに当たります。見つからないときは、アクション追加の画面の虫めがねで「優先」や「Priority」と検索
   - 初めて使うとき「サイレントモードへのアクセス（Do Not Disturb access）」の許可を求められるので、MacroDroid を許可する。Android 15 以降では MacroDroid 専用のモード（MacroDroid Do Not Disturb）が使われる
7. マクロ「Pomoroad 集中終了」
   - トリガー：同じく「集中終了」を含む
   - アクション：「音量」→「優先モード/通知のミュート」→「全通知を許可」、`pomoroad_focus` をオフ（false）
8. 手順 1 のマクロに、制約「変数 `pomoroad_focus` がオン」を足し、HTTP リクエストのあとに「ホーム画面を表示」と「読み上げ：今は集中の時間です」を足す

- Pomoroad は、集中を始めたときに「集中開始：あと25分（タスク名）」、休憩に入ったり一時停止して 8 秒たったときに「集中終了」を送ります。すぐ再開したときは送りません。集中中に Pomoroad を終了したときも「集中終了」を送ってから終わります
- 無料版の MacroDroid はマクロが 5 つまでです。足りないときは 6 と 7 を 1 つにまとめられます（トリガーを 2 つにして「もし〜なら」で分ける）
- 時計を見るためにスマホを点けるだけなら数えません（数えるのは、選んだアプリを開いたときだけ）

## うまくいかないとき

| こうなる | 確かめること |
|---|---|
| パソコンに「つながっていません」 | インターネットにつながっているか。「詳しい設定」の中継サーバーが `https://ntfy.sh` か |
| スマホでアプリを開いても、パソコンの「スマホから届いた知らせ」に出ない | MacroDroid の HTTP リクエストが GET か、URL のトピック名の最後に `-pc` が付いているか。MacroDroid のシステムログ |
| 「スマホのアプリ」とだけ出る | URL の最後のマジックテキストが置き換わっていない。「…」から選び直す（手入力では置き換わらないことがある） |
| おやすみモードにならない | ntfy アプリにトピックを登録したか（設定の「② スマホの ntfy アプリに送る」で通知が来るか）。MacroDroid に通知へのアクセスと、サイレントモードへのアクセス（Do Not Disturb access）を許可したか |
