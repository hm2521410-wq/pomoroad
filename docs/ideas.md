# 集めたアイデア

勉強・作業に集中するためのポモドーロタイマーについて、アプリのレビュー記事・ストアの紹介・時間配分の研究紹介などから集めたアイデアと、Pomoroad での扱い。
（調べた日：2026-10-11）

## 取り入れたもの

| アイデア | 出どころ | Pomoroad では |
|---|---|---|
| 25/5 にこだわらず、集中・短休憩・長休憩の長さを別々に変えられる | 各種レビュー | シンプル設定・カスタム並び・プリセット |
| 52/17 ルール（52 分集中＋17 分休憩） | DeskTime の調査として紹介 | プリセット |
| 90 分前後のリズム（ウルトラディアン）＋20 分休憩 | 睡眠研究者の仮説として紹介（確定した科学ではない） | プリセット |
| 時間を決めずに集中して、集中した長さで休憩を決める（フロータイム／Flowmodoro） | 生産性ブログ | フロータイムのモード（休憩＝集中÷5、最短・最長つき） |
| 集中・休憩・音・自動開始をひとまとめにした「流れ」 | 新しいタイマーアプリ | ロード（並び）＋マイプリセット |
| 終了時刻の表示 | 国内のシンプルなタイマー | 「10:10 に終了」の表示 |
| 終わりの音を変えられる・無音にもできる | 国内のタイマー | 集中／休憩で別の音、なしも選べる |
| 秒針の音・多くのアラーム音 | 海外のタイマー | 4 種類の秒針、10 種類の通知音 |
| 1 日の目標ポモドーロ数 | 複数のアプリ | 目標と進み具合のバー |
| 日・週・月の記録、ヒートマップ | 複数のアプリ | 棒グラフ・4 か月のカレンダー・タスク別 |
| 予定と実際の時間を比べる（Focus To-Do） | Focus To-Do の紹介 | タスクごとの見積もり／実際のポモドーロ数・時間 |
| 厳格モード（途中でやめにくくする） | Focus To-Do・Focusi など | 厳格モード（中断は確認つき・数えない） |
| 中断（気が散ったこと）を記録して後で見直す | ポモドーロ・テクニックの本来のやり方 | 「気が散った」記録（D キー） |
| 常に手前に出る小さなタイマー | Windows 用のフローティングタイマー各種 | ミニ表示 3 種類・全画面アプリより手前 |
| ブラウン・ピンク・ホワイトノイズ | 集中用ノイズの紹介記事 | 5 種類のノイズ＋扇風機・機内 |
| 環境音を重ねて自分のミックスを作る（Noisli など） | 環境音アプリ | 37 種類を重ねる・シーン 14・ミックス保存 |
| ホーム画面のウィジェット・ロック画面表示 | スマホアプリ | Windows のトレイアイコン（進み具合のリング）とタスクバーの進捗 |
| 自動で集中と休憩が切り替わる／切り替わらない | 国内アプリのレビュー（自動で進まない不満） | 休憩・集中それぞれ自動開始を選べる |

> 注：ノイズが集中に効くかは人によって差があり、研究の結果もまちまちです（ADHD 傾向の人で効果が見られた研究がある一方、3 割ほどは逆に成績が下がったという報告もある）。いろいろ試して自分に合う音を選ぶのがおすすめです。

## 次に足せそうなもの（候補）

- 休憩中のおすすめ行動（ストレッチ・水を飲む・遠くを見る 20-20-20）と、呼吸のガイド（4-7-8・ボックス呼吸）
- 集中の前に「この 25 分でやること」を 1 行書く、終わったら集中度を 5 段階で振り返る
- 科目・タグごとの集計（授業ごとの勉強時間）
- Polaris（予定・タスク）との連携：今日のタスクを取り込む、集中時間を記録として送る
- 時間割に合わせた自動開始（例：毎日 20:00 に 1 セット）
- 集中中に指定したアプリ・サイトを開いたら知らせる
- 環境音の追加（雪の夜の静けさ、街の雑踏、教室、船内、キャンプ場など）と、音ごとの「明るさ」つまみ
- スマホとの記録の同期
