## Pomoroad 1.2.0

### 新しくなったこと：見守り
集中中にパソコンやスマホをいじり出してしまったときに、声をかけて勉強に戻します。

- **パソコン**：集中しているあいだだけ、前に出ているアプリの名前と画面の題名を見て「勉強用／気が散る／どちらでもない」に分けます（画面の中身は見ません。記録はこのパソコンの中だけ）
- 気が散る画面（YouTube・SNS・ゲーム・買い物・チャットなど）を開いていると、20 秒は見逃し → 通知とミニ表示 → 1 分で読み上げて Pomoroad を前に出す → 3 分で「一時停止しますか？」（寄り道した時間は記録から外せます）。勉強用の画面に戻るとほめます
- 口調は「やさしい／コーチ／きびしめ」。残り時間・タスク名・今日のポモドーロ数を入れて声をかけます
- 勉強に使っている画面で注意されたら「**これは勉強用**」で覚えさせられます（題名の言葉・アプリ単位・このタスクのときだけ）。題名に「講義」「解説」などが入った動画は、はじめから勉強用です
- 設定に「見守り」タブ：直前に使った画面の判定を確かめる、最近使った画面をまとめて仕分ける、気が散るものの種類を選ぶ、声かけの段階と知らせ方を変える
- 統計に「寄り道した時間」「声かけの回数」「勉強用の画面にいた割合」、CSV に寄り道とスマホの列
- **スマホ（Android）**：MacroDroid と無料の中継サービス ntfy で連携。スマホで気が散るアプリを開いたらパソコンでも声をかけて記録し、集中中はスマホをおやすみモードにもできます。手順はアプリの「設定 → 見守り → スマホの設定のしかた」に、あなた用のトピック名と URL が入った状態で出ます

はじめは見守りがオン、スマホ連携はオフです。設定の「見守り」で変えられます。

### アップデートのしかた
1. トレイの Pomoroad のアイコンを右クリック →「終了」
2. 下の `Pomoroad-Setup-1.2.0.exe` を実行（上書きで更新。記録・タスク・設定はそのまま残ります）

署名をしていないので、「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
