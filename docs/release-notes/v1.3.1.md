## Pomoroad 1.3.1

### 直したこと
- スマホの設定のしかた（設定 → 見守り）：MacroDroid には「おやすみモード」という名前のアクションはなく、**「音量」→「優先モード/通知のミュート」**（英語表示では Priority Mode / Do Not Disturb）がそれに当たる、と書き直しました。集中開始では「優先通知のみ許可」、集中終了では「全通知を許可」を選びます。初めて使うときに「サイレントモードへのアクセス」の許可が必要です

### アップデートのしかた
- 1.3.0 を使っていて、GitHub のリポジトリが公開になっていれば、自動で届きます（「再起動して更新」を押すだけ）
- それ以外は、下の `Pomoroad-Setup-1.3.1.exe` を実行してください（上書きで更新。記録・設定はそのまま）
