## Pomoroad 1.3.0

### 変わったこと
- **自動アップデート**：起動して少したつと新しいバージョンを確かめ、見つけたら裏でダウンロードします。準備ができたら「再起動して更新」を押すだけです（押さなくても、次に終了したときに入ります）。集中中はお知らせを出しません
  - 1.3.0 にするときだけは、下の `Pomoroad-Setup-1.3.0.exe` を手で実行してください。次からは自動です
  - ポータブル版は自動で更新されません
- **ホワイトノイズの「いつ鳴らすか」を分かりやすく**：休憩中を「鳴らさない／集中と同じ音／休憩用の音」から選べます。音を選んだときの試し聞きは、パネルを開いている間だけになりました
- 直したこと
  - 設定でタブを切り替えると、設定の画面が閉じてしまう
  - 休憩用の音を選んだあと「集中中だけ鳴らす」にしても、休憩用の音が鳴り続ける。休憩中に音を選ぶと、パネルを閉じても休憩中ずっと鳴り続ける
- スマホ連携：「① パソコン側を確かめる」（中継サービスに送って受け取れるか）と「② スマホの ntfy アプリに送る」に分け、結果を表示するように。設定の見守りタブを開いていれば、集中中でなくてもスマホから届いた知らせを表示します

### アップデートのしかた（今回だけ）
1. トレイの Pomoroad のアイコンを右クリック →「終了」
2. 下の `Pomoroad-Setup-1.3.0.exe` を実行（上書きで更新。記録・タスク・設定はそのまま残ります）

署名をしていないので、「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
