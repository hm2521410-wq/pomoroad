## Pomoroad 1.1.0

### 変わったこと
- **雨・風・川・海・森・焚き火・虫・カエル・作業音が、ゆっくり移り変わるように**なりました。ループではなく続きを作り続けるので、同じところのくり返しになりません。雨の強さ・音の近さ・「ザー」と「ぽつぽつ」の割合などが数分かけて変わります。
- 変わり方の大きさは「ホワイトノイズ → 細かい設定 → 音の移り変わり」（一定／ひかえめ／ふつう／大きめ）で選べます。
- 鳥は「やって来て、同じ場所でしばらく鳴いて、去る」ように。雷や虫なども、にぎやかな時間と静かな時間が交互に来ます。
- **喫茶店の話し声を作り直しました**（日本語の音声合成で作った会話を何十人分も重ねたもの）。
- 図書館に、近くの席のひそひそ話・遠くのカウンターの声・小さな咳払いを追加。
- 設定 → データに「バージョンと更新」を追加。

### アップデートのしかた
1. トレイの Pomoroad のアイコンを右クリック →「終了」
2. 下の `Pomoroad-Setup-1.1.0.exe` を実行（上書きで更新。記録・タスク・設定はそのまま残ります）

署名をしていないので、「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
