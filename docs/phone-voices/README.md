# スマホ用の声かけ音声

MacroDroid の「読み上げ」の代わりに再生する音声です。VOICEVOX（無料の音声合成ソフト）で作りました。
各フォルダの `sample.mp3` で聞き比べて、気に入った声の `1.mp3`〜`4.mp3` をスマホに入れてください。

## セリフ

1. 今は集中の時間だよ。スマホを置いて、勉強に戻ろう。
2. あと少し、がんばろう。スマホは休憩のときにね。
3. そのアプリは、休憩になってから。
4. よし、スマホを置こう。集中に戻ろう。
